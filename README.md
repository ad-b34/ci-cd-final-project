# CI/CD Pipeline Implementation Project

This repository contains the Final Project implementation demonstrating a functional cloud-native CI/CD pipeline using GitHub Actions and OpenShift Pipelines (Tekton).

## Project Details
* **Project Name:** CI/CD Pipeline Integration
* **Components:**
  * Frontend: Node.js Pricing Service (`dealer-pricing`)
  * Backend: Python Details API (`product-details`)

## Automated Steps
1. **Linting:** Done automatically via GitHub workflows using `flake8`.
2. **Testing:** Automated local and cloud unit tests executed via standard Python test runners.
3. **Deployment Node:** OpenShift Container Platform managed pipelines.
